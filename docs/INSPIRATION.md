# Inspiration (Oct 2026 rebuild)

Short notes on the portfolios studied and what was borrowed.

| Site | What I took |
|---|---|
| brittanychiang.com | Sticky left column (name, role, short nav, socials) with the content scrolling on the right at desktop; collapses to a single column on mobile. Experience as a compact list: dates in a narrow left column, role and stack chips on the right. |
| leerob.com | Restraint: few colours, generous whitespace, short plain sentences in first person. Nothing animated that doesn't need to be. |
| joshwcomeau.com | Clear type scale and a single, confident accent colour; dark mode that respects the system setting with a manual toggle. |
| paco.me / rauno.me | Small, quiet details (hairline borders, muted secondary text) instead of big effects. |
| Colorlib "best data science portfolios" roundup (e.g. Aditya Ranjan) | Each project framed as problem -> data/approach -> outcome, with code and demo links side by side. |
| Interview Kickstart data-science portfolio guide (2026) | A few strong projects beat many weak ones: feature two, list the rest compactly. |
| Burtch Works data-analyst portfolio guide | The site is a professional overview first: who you are, what you can do, how to contact you, all above the fold. |
| DEV "best developer portfolios 2026" roundups | Hiring managers scan for evidence of real work, clear writing and technical depth; a CV link must be one click from the top. |

## The 6-second scan
Name, what I'm looking for, location, and buttons for projects / email / GitHub / CV all visible on first load.

## F1 touch
Kept only as a faint Albert Park circuit outline behind the intro, a thin kerb-stripe section divider, and a one-line note in the footer.

Sources: colorlib.com, interviewkickstart.com/blogs/articles/build-data-science-portfolio, elementor.com/blog/best-web-developer-portfolio-examples, dev.to/jtrevdev/best-developer-portfolio-websites-and-why-they-work, burtchworks.com.
